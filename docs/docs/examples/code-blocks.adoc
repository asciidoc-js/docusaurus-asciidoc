= Code Blocks Example

This page demonstrates various ways to include code in AsciiDoc documents.

== Basic Code Block

A simple code block with line numbers:

[source,python,linenums]
----
def fibonacci(n):
    """Generate Fibonacci sequence up to n"""
    a, b = 0, 1
    while a < n:
        yield a
        a, b = b, a + b

# Usage
for num in fibonacci(10):
    print(num)
----

== JavaScript Example

[source,javascript]
----
// Define a function
function greet(name) {
  return `Hello, ${name}!`;
}

// Use it
console.log(greet('World'));

// Or with arrow functions
const greeting = (name) => `Hello, ${name}!`;
console.log(greeting('AsciiDoc'));
----

== Highlighting Specific Lines

[source,javascript,highlight=2;4]
----
function calculate(a, b) {
  const sum = a + b;
  const product = a * b;
  const difference = a - b;
  return { sum, product, difference };
}
----

The lines 2 and 4 are highlighted above.

== Callouts

[source,javascript]
----
function example() {
  const x = 10;      // <1>
  const y = 20;      // <2>
  return x + y;      // <3>
}
----

<1> Declare first variable
<2> Declare second variable
<3> Return their sum

== Inline Code

You can also use inline code like `const x = 42;` or `function foo()` directly in your text.
